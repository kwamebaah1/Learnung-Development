# Fleet Management Dashboard

A modern, responsive dashboard for managing fleet operations, built with React, TypeScript, and Tailwind CSS.

## Features

- 📊 Driver statistics with interactive charts
- 🚗 Vehicle details and specifications
- 🗺️ Route management and tracking
- 📱 Fully responsive mobile design
- 🎨 Clean, professional UI with hover tooltips

## Quick Start

1. **Install dependencies**
   ```bash
   npm install

2. Start development server

    ```bash
    npm run dev
    Open in browser
    Navigate to http://localhost:3000
